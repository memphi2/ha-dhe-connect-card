# DHE Connect Card v0.7.3

This stabilization release updates the build and validation baseline while
preserving card YAML, entity discovery and runtime behavior.

## Highlights

- Validated against Home Assistant 2026.10 while retaining Home Assistant
  2026.4 as the HACS minimum.
- Refreshes the development lockfile with current compatible Vite, ESLint,
  Puppeteer, TypeScript-ESLint and type packages.
- Resolves the known transitive `undici`, `brace-expansion` and
  `source-map-js` dependency advisories.
- Keeps CI and release validation on the current Node.js 24 LTS baseline and
  explicitly supports Node.js 22.13 LTS or Node.js 24 and newer for local work.
- Regenerates the committed HACS bundle and source map with the refreshed
  Vite toolchain.

## Upgrade Notes

- Update through HACS, then reload the dashboard or clear the browser cache if
  Home Assistant still serves an older bundle.
- No YAML migration is required. Existing `device_id`, section, overview,
  action and entity override configuration remains unchanged.
- The card requires `ha-dhe-connect >= 1.8.4` and Home Assistant 2026.4 or
  newer.
