# DHE Connect Card v0.5.0

Initial public release of the DHE Connect Card.

This release starts the public GitHub release line from a clean repository
baseline. It is intended for HACS custom repository installation and manual
Home Assistant dashboard resource installation.

## Highlights

- Mushroom-style Lovelace card for the `stiebel_dhe_connect` Home Assistant
  integration.
- Home Assistant visual editor setup with mandatory device selection, native
  form-style controls, collapsible advanced groups and GUI configuration for
  sections, overview tiles, actions, hidden entity keys and entity overrides.
- Automatic entity discovery scoped to the selected Home Assistant device.
- Disabled and hidden registry entities stay hidden by default.
- Responsive compact default layout with wide-dashboard section reflow,
  configurable overview columns and dynamic tile sizing.
- Overview tiles support conditional colors, status badges, trend indicators,
  delta values and inline sparklines when Home Assistant attributes provide
  change or history data.
- State-aware icon colors and optional meaningful animations for water flow,
  heating, bath fill, timers, wellness programs, radio, safety, status and
  alarms.
- Optional display-style button layout for Eco mode, wellness programs, bath
  fill, timers and temperature memories.
- Weather, radio, diagnostics and support-mode sections.
- Home Assistant/Mushroom-style `tap_action`, `hold_action` and
  `double_tap_action` support.
- Guarded service calls with visible error feedback.
- German and English structured translations with CI validation.

## Installation

Recommended HACS custom repository URL:

```text
https://github.com/memphi2/ha-dhe-connect-card
```

The dashboard resource should be:

```yaml
url: /hacsfiles/ha-dhe-connect-card/ha-dhe-connect-card.js
type: module
```

Minimal card config:

```yaml
type: custom:dhe-connect-card
device_id: <home_assistant_device_id>
```

Prefer creating the first card through the visual editor so Home Assistant can
write the correct device ID.
