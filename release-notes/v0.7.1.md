# DHE Connect Card v0.7.1

This maintenance release makes existing device-scoped card configurations
resilient to the Home Assistant 2026.8 device-registry split and updates the
release toolchain to the current Node.js LTS line.

## Highlights

- Existing cards with a stale `device_id` now recover automatically when Home
  Assistant exposes exactly one registered DHE device after a device split.
- Multiple DHE devices remain explicit: the card does not select one silently.
  Open the visual editor, choose the intended DHE device, and save the card.
- Support diagnostics now inspect the resolved device, keeping entity audits
  accurate after a successful recovery.
- CI and release jobs run on Node.js 24 LTS.

## Compatibility

- Required integration baseline: `ha-dhe-connect >= 1.8.4`.
- Existing modern `device_id` YAML remains valid.
- The automatic recovery applies only to an unambiguous single-DHE setup;
  multi-device setups require a one-time editor re-selection after the Home
  Assistant upgrade.
