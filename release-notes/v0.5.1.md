# DHE Connect Card v0.5.1

Stabilization release focused on production hardening and regression prevention.

## Highlights

- Stronger release validation:
  - compatibility check now validates bundle source-map linkage and source-map
    integrity
  - changelog/version/date consistency is validated
  - README latest-release link must match the tagged version
- Stronger docs validation:
  - `docs-check` now also runs release-readiness tests
  - screenshot references in README are verified against tracked assets
- Accessibility improvements:
  - editor help tooltips are semantic keyboard-focusable buttons
  - foldout summaries have explicit focus-visible outlines
  - support mode lists expose ARIA labels
  - radio favorites expose list semantics with `aria-pressed` state
- Performance stabilization:
  - lighter cache signatures for support-model regeneration
  - memoized renderable-section filtering per render signature
  - overview signature avoids serializing full sparkline arrays
- Regression coverage expanded for the above behavior.

## Compatibility

No breaking YAML semantics were introduced. Existing `v0.5.0` configurations
remain valid, including migration behavior for legacy pre-`0.5.0` top-level
`entity` anchors.
