# DHE Connect Card v0.6.2

Stabilization release focused on release reliability and clearer user-facing
documentation.

## Highlights

- Removed deprecated dependency noise in install checks by upgrading `jsdom` to
  `^29.1.1` (removes the deprecated `whatwg-encoding` transitive path).
- Added a lockfile metadata gate (`npm run deprecation-check`) to block
  deprecated package entries from creeping back in.
- Added a strict CI install guard so workflows fail when `npm ci` emits
  deprecation warnings.
- Improved README onboarding with a short visual-editor quick-start flow and
  updated links to current release notes.

## Compatibility

No breaking YAML semantics were introduced. Existing `v0.6.1` configurations
remain valid.
