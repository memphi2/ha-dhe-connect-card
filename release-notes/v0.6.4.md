# DHE Connect Card v0.6.4

Stabilization release focused on final post-legacy baseline hardening, editor
cleanup and release hygiene.

## Highlights

- Removed runtime legacy/fallback migration paths (`entity` anchor migration,
  legacy wellness key alias remapping, and legacy `compact` tile-size mapping).
- Simplified editor config update flow and reduced redundant update churn.
- Tightened overview internals by keeping grouping/condition helpers private and
  validating behavior through the public overview tile API.
- Cleaned dead editor style surface and aligned translation/release-readiness
  checks with the new baseline.

## Compatibility

- `ha-dhe-connect >= 1.8.4` is required for current card releases.
- Existing `device_id`-based `v0.6.3` YAML stays valid.
- Legacy top-level `entity` card anchors are no longer migrated.
