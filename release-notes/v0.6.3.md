# DHE Connect Card v0.6.3

Stabilization release focused on visual-editor ordering consistency and section
management reliability.

## Highlights

- Restored the dedicated `Sections` block in the visual editor, including
  explicit section enable/disable and drag-to-reorder behavior.
- Reordered the editor flow to: Actions -> Sections -> Overview tiles ->
  per-section entity editors.
- Fixed section ordering drift so the per-section editor blocks follow the
  configured section order.
- Added regression coverage for editor top-level ordering and section ordering
  after drag operations.

## Compatibility

No breaking YAML semantics were introduced. Existing `v0.6.2` configurations
remain valid.
