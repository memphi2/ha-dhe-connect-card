# DHE Connect Card v0.7.0

This release moves the card onto a clean, post-legacy baseline and packages the
latest stabilization work for public use.

## Highlights

- Removed remaining legacy/fallback migration paths from runtime config
  normalization and the visual editor.
- Kept `device_id` as the mandatory anchor and documented the migration baseline
  clearly across README, migration docs and configuration docs.
- Removed legacy wellness key alias remapping and legacy `compact` tile-size
  fallback behavior.
- Simplified editor update flow, reduced dead style/API surface, and tightened
  overview internals.
- Restored deterministic discovery-cache signatures so cache reuse is stable
  even when Home Assistant registry/state objects are rebuilt with different key
  insertion order.

## Compatibility

- Required integration baseline: `ha-dhe-connect >= 1.8.4`.
- Existing modern (`device_id`-based) YAML remains valid.
- Legacy top-level `entity` card anchors are no longer migrated.
