# DHE Connect Card v0.6.0

Stabilization release focused on release readiness, editor robustness and lower
maintenance risk.

## Highlights

- Diagnostics section hardening:
  - selected diagnostics stay visible even when HA marks some diagnostic
    entities as integration-disabled in the entity registry
- Visual editor hardening:
  - entity override rows now keep a working selector when `ha-selector` is not
    registered by the running HA frontend
  - fallback path uses `ha-entity-picker` with matching domain filtering
- Discovery performance stabilization:
  - `DiscoveryCache` now short-circuits discovery work when config and HA object
    references are unchanged
  - registry/state signatures were reduced to lighter deterministic strings to
    lower per-render churn
- Smoke/audit noise reduction:
  - HA `unsupported_grant_type` token revoke responses are handled as a known
    variant, followed by explicit localhost token cleanup

## Compatibility

No breaking YAML semantics were introduced. Existing `v0.5.x` configurations
remain valid, including migration behavior for legacy pre-`0.5.0` top-level
`entity` anchors.
