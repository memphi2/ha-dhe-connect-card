# DHE Connect Card v0.7.2

This stabilization release makes the visual editor and release pipeline more
resilient on current Home Assistant versions. Card YAML, entity discovery and
existing dashboards remain compatible.

## Highlights

- Uses Home Assistant's current `ha-input` editor control in place of the
  deprecated text-field component.
- Declares Home Assistant `2026.4.0` as the minimum HACS version baseline.
- Validates the finished HACS ZIP before publication, including its exact
  layout, path safety and privacy/legal hygiene.
- Extends browser smoke coverage to verify editor controls, accessible help
  labels and emitted configuration changes.

## Upgrade Notes

- Update through HACS, then reload the dashboard or clear the browser cache if
  Home Assistant still serves an older frontend bundle.
- This card requires `ha-dhe-connect >= 1.8.4` and Home Assistant `2026.4` or
  newer.
