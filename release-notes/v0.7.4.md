# DHE Connect Card v0.7.4

This is the local development baseline following the published `v0.7.3`
release. It is not a published GitHub release.

Prepares for the announced Home Assistant 2026.11 frontend and Marketplace
changes: switch labels use the new component contract, installation guidance
covers Marketplace and existing HACS resources, and CI targets Node.js 26 LTS.
Local fixture and browser smoke checks do not replace a live 2026.11 test.
