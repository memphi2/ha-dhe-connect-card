# DHE Connect Card v0.7.4

Version 0.7.4 focuses on reliable controls, faster discovery, accessible editor
interactions and safer maintenance. Existing dashboard YAML continues to work;
no migration or new configuration flags are required.

Prepares for Home Assistant 2026.11 frontend and Marketplace
changes: switch labels work with both tested component generations, installation guidance
covers Marketplace and existing HACS resources, and CI targets Node.js 26 LTS.
Local fixture and original-HA-component browser checks do not replace a live
2026.11 test.

The Marketplace and dashboard card picker now display the name
Stiebel Eltron DHE Connect Card. Existing YAML uses the same card type.

## Stabilization

- Integrate pending dependency updates and keep routine bot PRs disabled while
  retaining grouped security updates and full dependency audits.
- Climate sliders send the selected temperature even while HA omits the current
  target; shared validation keeps setpoints within the device's bounds.
- Pending gestures are cancelled when card settings change, so delayed actions
  cannot target the previously configured entity.
- Turning off the last section now keeps the selection empty.
- Cold discovery avoids repeated name and identity normalization.
- Translation checks cover dynamic labels and option maps as well as literal
  keys. Support exports now include the loaded card version.
- Release archives must contain nonempty assets matching the validated build,
  with unique filenames and valid source maps.
- Correct service-call locking after reconnecting the card and overview cache
  invalidation after HA formatting changes.
- Faster support diagnostics and discovery on large dashboards; disabled
  overview sections no longer build tile models.
- Support exports use fresh replacement identifiers for each download, not
  persistent hashes of private IDs. Existing JSON field names are retained.
- Visible editor help for keyboard, mouse and touch, with Escape dismissal.
- Real frontend tests cover device selection, entity overrides, text inputs
  and single-toggle switch behavior on the minimum and current package baseline.
- Scheduled dependency audits and a release audit gate include build tooling.

## Compatibility And Validation

- Requires Home Assistant 2026.4 or newer and a clean installation of
  `ha-dhe-connect` 1.8.4 or newer.
- Validated with 336 automated tests, 12 browser layout scenarios and original
  HA frontend packages `20260325.5` and `20261028.3`.
- Dependency audits cover development tooling as well as runtime packages.
- The release workflow builds and verifies the JavaScript bundle, source map
  and HACS archive before publication.

## Updating

Update the existing card through your configured dashboard plugin manager or
replace the JavaScript resource with the release asset for a manual install.
Keep the existing `custom:dhe-connect-card` type and resource URL. Reload
dashboard resources and refresh the browser after updating.

The support export includes `card.version` to identify the loaded release.
Review exports before sharing because selected options and coarse device status
remain included. See the [installation guide](https://github.com/memphi2/ha-dhe-connect-card/blob/v0.7.4/docs/installation.md)
for the supported installation paths.
