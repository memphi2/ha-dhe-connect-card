# DHE Connect Card v0.6.1

Stabilization release focused on entity-surface parity with the backend
integration.

## Highlights

- Synced entity surface with `ha-dhe-connect` `v1.8.0`.
- Added diagnostics sensor key `wellness_runtime_normalized` to card catalog and
  integration fixture mapping.
- Added matching entity labels in `en` and `de` translations.
- Documented the new diagnostics sensor in configuration docs.
- Kept icon semantics consistent:
  - wellness program switches keep wellness visuals
  - `wellness_runtime_normalized` uses timer/runtime visuals as telemetry

## Compatibility

No breaking YAML semantics were introduced. Existing `v0.6.0` configurations
remain valid.
